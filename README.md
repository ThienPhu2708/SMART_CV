📝 Giới thiệu dự án
SmartCV là hệ thống hỗ trợ tự động hóa quy trình sàng lọc hồ sơ ứng viên (CV) dựa trên công nghệ học sâu. 
Hệ thống kết hợp giữa Mạng Nơ-ron nhân tạo MLP (Multi-Layer Perceptron) và các quy tắc Logic nghiệp vụ (AND, OR, NOT, XOR) để đưa ra điểm số phù hợp (Matching Score) một cách khách quan và chính xác.
